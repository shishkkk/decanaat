При DEMO_MODE=true доступны отдельные кнопки быстрого входа для жюри. Пароли проверяются сервером; база содержит только bcrypt-хеши. Быстрый вход использует фиксированный серверный список демоаккаунтов и не передаёт пароль клиенту.

Отключение DEMO_MODE выключает быстрый вход и автосоздание данных, но не удаляет уже созданные аккаунты и не меняет их публичные пароли. Для реального университета нужна отдельная система регистрации/SSO и смены учётных данных; этот проект предназначен для демонстрации.
