CAMPUS · Цифровой деканат

Для Windows установите Node.js 24 или новее, распакуйте папку целиком и запустите Start.cmd. На macOS/Linux выполните node serve.mjs из распакованной папки и откройте http://127.0.0.1:3048/index.html.

Два входа для жюри: alex — студент, vera — преподаватель. Общий демонстрационный пароль CampusDemo!2026. Доступен быстрый вход.
Изменения сохраняются в campus.sqlite рядом с HTML. Файл содержит личные записи демонстрации, не публикуйте его. Для развёртывания по HTTPS используйте полную серверную сборку проекта.

Если предыдущая версия уже открыта, Start.cmd выберет свободный порт и откроет актуальный адрес. Новый раздел Профиль содержит пропуск, зачётку, план и посещаемость. На главной доступны заметки, истории, ближайшая пара и услуги. В «Расписании» откройте учебный календарь для просмотра недели, записи на события и экспорта .ics. В «Учёбе» доступен график по истории оценок.
